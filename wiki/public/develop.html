Develop

git clone https://github.com/simply-sunny/vtdownloader-ui-refresh
cd vtdownloader-ui-refresh
./gradlew buildAll

The jars are in build/libs. ./gradlew :26.2:runClient starts the game with this mod and VTDownloader.
