Troubleshooting

ProblemFix
requires vt_downloaderInstall VTDownloader for your Minecraft version.
The screen looks like VTDownloader's ownCheck that this mod's jar is in mods and matches your Minecraft version.
error while trying to get the packsCheck your connection and that vanillatweaks.net is up, then press the reload button.
Download stays grayed outSelect at least one pack, and check the name. The field says what's wrong with it.
A file with that name already existsChoose another name, or remove the old pack from your resource packs folder.
That file name is a reserved Windows nameChoose another name. Names like CON don't work on Windows.
The Selected packs panel is gone, with no arrowThe window is under 400 GUI pixels wide. Enlarge it or lower the GUI scale.
Installed is emptyIt only reads zips and folders made by Vanilla Tweaks, which hold a Selected Packs.txt. Packs downloaded elsewhere don't count.
An icon looks out of dateDelete config/vtd_ui_refresh/cache/icons and open the screen again.
A pack's page says No previewThe preview didn't download, or it's a WebP, which the game can't read. Delete config/vtd_ui_refresh/cache/previews to try again.
A pack doesn't applyTurn it on under Resource Packs. Downloading doesn't enable it.
Broken configDelete config/vtd_ui_refresh/config.json and relaunch.

Report issues with logs/latest.log and your Minecraft, mods and loader versions, or upstream if VTDownloader does the same without this mod.

Limits

  • VTDownloader sets the Vanilla Tweaks version when it's built. There's no picker in the game.
  • This mod uses VTDownloader's internals, so a new VTDownloader release can need a new build of this mod.
  • Resource packs only. Data packs and crafting tweaks aren't available.
  • The pack list needs a connection to vanillatweaks.net, and so do icons that aren't cached yet.
