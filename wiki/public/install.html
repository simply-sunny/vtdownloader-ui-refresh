Install

For Minecraft 26.2. Java 25. Client-side only.

  1. Install Fabric Loader 0.19.3 or newer.
  2. Install Fabric API.
  3. Install VTDownloader 2.6.0 or newer.
  4. Put the jar from GitHub Releases in mods. Coming soon to Modrinth + CurseForge
